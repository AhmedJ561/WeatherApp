# Weather App

A small Flutter weather application that shows current weather, a short hourly forecast, and additional details for a selected city using the OpenWeatherMap API.

## Features
- Search for cities with live suggestions (OpenWeatherMap geocoding).
- Current temperature, weather condition and icon.
- 5-item hourly forecast preview.
- Additional info: humidity, wind speed, air pressure.
- Refresh control and simple, responsive UI that supports light/dark themes.

## Stack
- **Language(s):** Dart (Flutter)
- **Framework/runtime:** Flutter (Android / iOS / Web / Desktop)
- **Notable packages:**
  - http — for API requests
  - intl — for date/time formatting
  - cupertino_icons — platform icons

## Project layout
```
lib/
  main.dart             # App entrypoint — sets orientation and fires WeatherScreen
  weather_screen.dart   # Main UI and API interaction (OpenWeatherMap)
  hourly_forecast.dart  # Small widget used by the horizontal hourly list
  additional_info.dart  # Widget for humidity / wind / pressure tiles
assets/
  weather.png           # App icon / sample asset used by flutter_launcher_icons
android/                # Android platform project (auto-generated by Flutter)
ios/                    # iOS platform project (auto-generated by Flutter)
macos/                  # macOS platform project (auto-generated)
linux/                  # Linux platform project (auto-generated)
windows/                # Windows platform project (auto-generated)
web/                    # Web build artifacts / web entry
test/                   # Tests (currently empty)
pubspec.yaml            # Flutter dependencies & assets
```

How it fits together:
- `main.dart` initializes the app and shows `WeatherScreen`.
- `weather_screen.dart` handles user input, requests (forecast and geocoding) to OpenWeatherMap, parses the JSON, and builds the UI using `HourlyForecast` and `AdditionalInfo` components.

## Requirements
- Flutter SDK >= 3.4.0 (see `pubspec.yaml` environment)
- An OpenWeatherMap API key (free tier available at https://openweathermap.org/)

## Quick start — run locally
1. Clone the repo:
```bash
git clone https://github.com/AhmedJ561/WeatherApp.git
cd WeatherApp
```

2. Install dependencies:
```bash
flutter pub get
```

3. Add your OpenWeatherMap API key:
Create a file `lib/api_key.dart` with the following content (replace the placeholder with your key):

```dart
const String apiKey = 'YOUR_OPENWEATHERMAP_API_KEY';
```

> Note: The app imports `package:weather_app/api_key.dart` in `weather_screen.dart`. Keep this file out of source control or add your preferred secret management. (A gitignore rule is recommended for API keys.)

4. Run the app:
```bash
flutter run
# or target a specific platform:
flutter run -d chrome
flutter run -d emulator-5554   # an Android emulator, for example
```

## Usage
- Type at least two characters in the search field to get city suggestions.
- Tap a suggested city or press Enter to load weather for that city.
- Tap the refresh icon in the app bar to fetch the latest data.
- Temperatures are converted from Kelvin (OpenWeatherMap) to Celsius in the UI.
